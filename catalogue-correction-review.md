## Audit boundary

This is an evidence-backed deterministic pass over the full catalogue: exact
normalization collisions, fuzzy title pairs, suspicious artist strings, book
context, source filenames, the current B2 manifest, and targeted authoritative
references. An optional model-assisted second pass could find additional subtle
semantic errors, but it would require explicit permission because it sends the
catalogue metadata to an external model API.
